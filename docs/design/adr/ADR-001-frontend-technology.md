# ADR-001：正式前端继续采用 React

- 状态：已接受
- 日期：2026-08-20

## 决策

正式前端采用 React + TypeScript + Vinext + Vite，沿用已经确认的自定义 UI，不引入 Ant Design。当前由一个工程承载 H5、管理后台和现场大屏，并共享 API 客户端、领域类型和主题资源。

## 理由

原型已经使用 React 和 TypeScript，视觉与交互已经由业务确认。继续 React 可减少整体换栈成本，也能直接复用现有样式；业务页面没有 SEO 必要。

## 约束

正式业务请求必须经 `app/api.ts` 和后端规则处理，禁止继续增加只保存在浏览器内存中的业务事实。页面组件可分阶段拆分，但不得因此改变订单只读后台等已冻结规则。
