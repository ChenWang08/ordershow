# ADR-001：正式前端继续采用 React

- 状态：已接受
- 日期：2026-08-20

## 决策

正式前端采用 React + TypeScript + Vite，拆分为 H5、管理后台和现场大屏三个 SPA，并共享 OpenAPI 客户端、领域类型和主题资源。

## 理由

当前原型已经使用 React 和 TypeScript，视觉、交互和部分文件解析逻辑可作为参考。继续 React 可减少整体换栈成本；业务页面没有 SEO 或 SSR 必要。

## 约束

当前单文件原型不能直接扩展为生产代码，必须进行页面、组件、状态和接口层拆分。若最终维护团队只支持 Vue，应在正式工程骨架建立前一次性变更本 ADR。
