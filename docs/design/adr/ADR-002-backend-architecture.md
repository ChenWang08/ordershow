# ADR-002：采用 Spring Boot 模块化单体

- 状态：已接受
- 日期：2026-08-20

## 决策

后端使用 Java 21 + Spring Boot 稳定版本构建模块化单体，MySQL 为唯一业务事实来源。第一期不引入微服务和外部消息队列；耗时任务由独立 Background Worker 通过 MySQL DB Task Queue 执行。

## 理由

目标规模为千人级同时在线和几百个商品，单体可以满足性能需求；订单、导入和抽奖更需要清晰事务边界。模块化单体加独立 Worker 运行角色可以分别扩展 API 和耗时任务，部署和现场故障排查成本仍较低。

## 后果

模块边界必须在代码包、应用服务和数据库访问层落实。将来只有当统计、导入或抽奖出现独立扩缩容需求时，才按模块边界拆分服务。
