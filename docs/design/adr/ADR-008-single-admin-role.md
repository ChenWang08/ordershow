# ADR-008：一期采用单一管理员角色（历史基线）

- 状态：已被 ADR-009 取代
- 日期：2026-08-20

## 决策

历史基线为一期只有 `ADMIN` 角色，拥有全部后台配置能力；系统支持多个具名管理员账号。该决策已被 ADR-009 取代，当前以 [ADR-009](ADR-009-department-shared-account-isolation.md) 的 2026-10-07 扩展为准，采用超级管理员、部门管理员及独立成员，按部门范围和六项模块权限校验。

## 后果

当时没有模块权限配置页面和权限表。V035 已新增成员角色与 `admin_user_permission`，成员权限管理已实现；本条只保留历史决策，不作为当前功能限制。
