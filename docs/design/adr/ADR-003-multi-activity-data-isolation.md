# ADR-003：单系统支持多活动并按活动隔离数据

- 状态：已接受
- 日期：2026-08-20

## 决策

系统允许创建、运行和归档多场活动。草稿活动时间可以重叠，但已发布且未截止的活动不得重叠，以保证通用 H5 入口始终只能解析出一场可下单活动。所有活动业务表包含 `activity_id`；活动编号用于运营识别，历史数据不被新活动覆盖。

## 约束

- 核心唯一约束必须包含活动 ID；
- 通用 H5 入口由服务端按发布状态和可信时间解析活动，API 从解析结果、令牌或后台上下文取得活动 ID，并验证访问权；
- 缓存键和对象存储键包含活动 ID；
- 禁止把浏览器保存的“当前活动”偏好作为业务数据的权威来源。
