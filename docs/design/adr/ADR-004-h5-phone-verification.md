# ADR-004：H5 仅通过白名单手机号验证

- 状态：已接受
- 日期：2026-08-20

## 决策

H5 不发送短信验证码。客户选择活动和客户类型后，后端按活动 ID、客户类型和标准化手机号精确匹配活动白名单。

同一手机号允许分别存在于综合和特渠通道；同一活动、同一客户类型内手机号重复时，导入批次不能确认，必须先处理异常。

验证成功后默认设置 Secure、HttpOnly、SameSite Cookie，凭证绑定活动、活动客户和客户类型；到期时间设为活动结束时间，活动提前截止、客户被停用或凭证被撤销时可更早失效。H5 与 API 默认通过同站点托管入口提供，写操作增加 CSRF Token 和 Origin 校验，不在浏览器存储或 URL 中保存凭证。只有跨站 API 无法改为同站点入口时才使用 Bearer Token。不因连续验证失败永久锁定，但实施宽松 IP/设备频率限制和访问日志。

## 已接受风险

该方式只能证明访问者知道白名单手机号，不能证明其持有该手机。业务方以低操作门槛为优先并接受该身份冒用风险。

## 补偿控制

- 活动入口不可枚举或批量扫描；
- 接口限流和异常频次告警；
- 凭证仅能访问一个活动客户的订单；
- Cookie 不能被 JavaScript 读取，写操作仍执行 CSRF/Origin 校验；
- 手机号不出现在大屏和普通日志；
- 订单提交、修改、撤回和重新提交只能由客户在 H5 操作；管理员只能在后台查看和导出订单，不能改变订单内容或业务状态。
