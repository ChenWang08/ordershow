# ADR-009：商品和白名单采用独立全量导入批次

- 状态：已接受
- 日期：2026-08-25

## 背景

商品和白名单 Excel 的业务含义是“本次完整名单”，不是针对上一版本的增量补丁。跨版本展示新增、更新、未变化或移除会让管理员误以为需要维护版本差异，也会使图片是否继承变得不明确。

## 决策

1. 每次商品或白名单 Excel 都创建独立待发布批次，不计算或展示跨版本新增、更新、未变化和移除状态。
2. 上传、解析、编辑预览行和选择图片 ZIP 只影响导入任务及 staging 数据，不改变当前有效业务版本；只有管理员确认且物化全部成功后才原子切换当前版本。
3. 商品状态只展示“有效、待核对、待完善”；白名单状态只展示“有效、待处理”。商品另提供“价格有效、价格待完善”筛选，图片状态只展示“已匹配、待确认、未匹配”。
4. 图片 ZIP 属于本次商品 Excel 批次。重新选择 Excel 时清空待确认图片，新版本不继承上一版本的 ZIP 图片或手工维护图片；没有本批次匹配图片的商品统一为“未匹配”。
5. 旧发布版本及其图片关联继续保留，只用于历史订单、审计和受控回滚，不参与当前页面状态计算。

## 后果

导入页面只需要解释当前文件的数据质量和图片匹配结果，管理员确认前不会影响线上目录。系统仍可保存临时导入任务、原文件和预览行用于校验与审计，但这些记录不是当前有效商品或白名单。重新导入商品时必须重新提供本版需要的图片。
