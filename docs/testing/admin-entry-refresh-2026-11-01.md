# 后台每次进入模块读取（2026-11-01）

## 交付与行为

仅修改管理后台前端、测试和说明；无后端 API、数据库迁移、业务数据写入或部署。未重启本机业务服务，当前运行页面不会因为源码修改自动升级。

删除的是前端普通刷新入口，不是后端读取能力：活动信息及各模块的读取接口保留，由进入页面等动作触发。轻量活动列表用于切换活动，不会逐场加载所有活动详情和模块数据；自动读取也不代表服务器持续替所有活动刷新。

- 初次进入后台仅获取身份、轻量活动列表、所选活动详情和当前可访问模块；默认概览自动读取金额、箱数、吨数与客户提交进度。未打开的商品、白名单、到场、订单、抽奖、成员、账号及日志均不加载。
- 首次打开以及从其他模块返回时读取最新数据。保留筛选、页码和最后成功快照；不在页面空闲时轮询。活动基础资料随导航更新，首屏复用入口详情，避免重复请求。
- 普通刷新按钮只保留概览“刷新统计”、订单列表“刷新订单”、审核“刷新审核”。删除“刷新活动信息”“刷新当前模块”“刷新基础信息”“刷新中奖统计”“更新商品选项”及日志刷新。读取失败才显示重试；保存结果不确定时的原有“刷新列表”核对入口保留，避免重复新增。
- 同一活动内，未保存编辑或导入预览优先保留，不被自动加载或迟到响应覆盖；保存/取消后恢复读取。后台已执行的导入任务继续运行，隐藏页面停止查询进度，返回恢复。
- 切换活动、刷新/关闭浏览器不弹未保存确认，本地未保存编辑可丢失；已保存内容不受影响。删除、发布、截止等业务确认以及明确关闭编辑抽屉的原有保护保留。
- 抽奖继续使用整份已保存规则接口，不拆轮次摘要/详情。进入读取配置、公共人数和中奖统计；适用时读取商品选项。“手动试算”只计算当前选中轮，进入、编辑、切换轮次和保存不自动试算，候选名单复用该次结果。
