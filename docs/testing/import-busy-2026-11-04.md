# 商品与白名单导入防重复点击：定向验证

日期：2026-11-04。状态：源码与相关验证完成，尚未部署。

## 改动范围

- 商品和白名单导入参照现场到场名单，增加处理中按钮变淡、禁用及“正在处理…”/“正在发布…”提示。
- 保护覆盖文件解析、上传、预览读取、确认发布、正式列表读取和取消；商品图片ZIP解析也使用同一模块保护。
- 处理期间禁止确认、替换文件、移除、重新导入、手动新增、编辑和删除。处理函数同步拦截快速连点，防止按钮重新渲染前重复提交。
- 成功或错误返回后解除禁用。发布已成功、正式列表读取失败时，沿用既有“替换成功，请刷新核对，请勿重复确认”处理。
- 三类导入沿用现有`waitForImport`，本次没有修改任务查询、后端代码或数据库结构。

## 任务查询行为

确认接口返回后立即查询任务；若尚未完成，在上次请求结束后等待1000毫秒再查，最多90次。模块不可见时暂停查询，后台已受理的任务继续执行；回到模块后按现有机制恢复。完成、失败、取消、等待超时或请求取消时结束等待，空闲页面不启动该查询。

90次查询不等于严格90秒，网络耗时及隐藏等待另计；等待超时也不会取消后台任务。这部分为既有行为，本次只核对代码，未新增轮询或作性能测量。

5. 实际商品及白名单页面静态渲染时，发布按钮、Excel/ZIP输入、移除、新增和编辑入口禁用，删除入口隐藏；失败后恢复。
