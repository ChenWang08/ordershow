# 订货排行布局与一屏适配（2026-11-04）

## 修改范围

仅调整订货排行前端组件及相关样式：

1. 第一行整体靠右，按金额/吨数切换、客户类型、大区、项目组、品种、确认查询、重置、手动刷新、最近刷新时间排列。切换紧邻客户类型之前，与下拉框在同一行且垂直居中；不再预留独立切换行。
2. 下一行的订单金额和订货吨数并排，以两项汇总整体在页面正中间显示；两项标签和数值各自居中，窄窗口允许换行。
3. 剩余高度用于三列客户排行及右侧分公司榜。90名仍按1–30、31–60、61–90分列。

删除大标题、“历史回看”和“当前结果”摘要及其占位。保留待确认、加载失败及选项失效等必要提示。所有现有字体大小保持不变，沿用字体和字重，通过顶部间距、榜单标题留白及行间空间适配高度。行高最低19px，容纳原有分公司12px文字及边框；少量结果保留紧凑行高。高度不足时使用页面滚动，分公司超过30条时保留榜内滚动。

沿用现有进入页只读选项、确认后查询、手动刷新使用最后成功条件、重置等待确认、失败保留旧结果和刷新时间的行为。历史状态只移除显示文案，数据读取规则保持原有实现。

无后端代码、接口参数、数据库或统计排序逻辑改动；未构建或部署本地镜像，未操作业务服务。

### 切换与筛选合为一行

将排行切换移入筛选工具栏，作为客户类型之前的首项，保留切换控件原有9px字号和金色选中样式。筛选按钮样式限定为查询/重置和刷新按钮，避免切换移入后继承筛选按钮的12px字号；切换容器与32px下拉框垂直居中。桌面工具栏同排靠右，小窗口沿用换行；汇总居中及榜单布局保持原样。

本轮重新运行26项排行组件/筛选测试、定向TypeScript和修改文件ESLint检查，全部通过。真实React和合成HTTP的浏览器专项通过，测量确认切换是工具栏第一项、后接客户类型、与下拉框同排且中心线一致；1920×1080、2560×1440、1366×768下金额/吨数两种模式均完整显示90条客户和30条分公司数据，14类元素原字号不变。原查询/重置/刷新、失败恢复、历史数据状态、空列表、小窗口滚动和品种弹层专项同时通过，无页面异常。

展开顶部栏的测试在测量时将鼠标停在栏内，避免工具栏点击触发既有自动收起计时而影响测量；组件自动收起逻辑未修改。无后端改动、整站构建或镜像部署。
