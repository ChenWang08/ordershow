# 订单吨数按可计算明细累加

## 规则及范围

- 单条吨数按箱数 / 每吨箱数计算，保留六位小数；无有效系数按 0 计入。
- 整单累加各条吨数，订单展示三位小数；全部无法换算显示 0.000，无额外缺失提示。
- 覆盖 H5 提交、变更审核、后台创建/调整/试算、商品系数同步、Excel 分组汇总与看板零值展示。
- V036 使用已保存明细补齐当前订单、历史版本、修改申请及审核原订单快照的汇总，不按当前商品系数重算历史数据。
- 保留看板快照及幂等重放回执。已有看板快照采用可计算明细累加口径，旧空吨数在展示时兼容为零，不删除历史快照。
