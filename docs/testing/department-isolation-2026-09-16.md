# 部门隔离修复

> 历史记录（2026-09-16）。2026-10-07 已增加独立成员和六项模块权限；当前规则见 [权限矩阵](../design/05-security-concurrency-audit.md)，成员专项验证见 [测试说明](../../tests/README.md)。下文“无活动创建引导”仅适用于管理员；成员不创建活动。模块权限拒绝会触发身份同步和模块清理，不一律使整个后台报活动加载失败。

后台先认证，再通过授权活动列表选择活动，最后调用后台详情和统计接口。无活动显示空状态，仍支持创建活动；超级管理员仍可管理部门。部门权限按活动归属决定，包含本部门历史活动及超级管理员代建活动。

账号活动偏好按账号 ID 保存；旧全局偏好不再采用。退出卸载后台工作区，旧异步结果不再写回；跨标签切换账号在聚焦和周期身份检查时清空原工作区。后台 401/403/404 会清除活动工作区并要求重新加载。

新增统计接口：GET /admin/activities/{activityId}/ranking。H5 和大屏专属公开入口保持原有规则。

验证：`node --test tests/department-isolation.test.mjs` 覆盖无活动、历史活动、失效活动偏好、拒绝访问和迟到响应。

独立接口验证：启动 docker-compose.test.yml 的 backend-test 后运行 `node scripts/test-department-isolation.mjs`。脚本固定连接 8180 和 order_show_e2e 测试库，验证两个部门的列表、详情、统计、商品、客户、订单、抽奖、审计及创建权限；测试数据不会进入业务库。
